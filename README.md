# Projeto 1, EBAC

Este projeto consiste em uma calculadora desenvolvida em Python, automatizada por meio de um script em Shell (`.sh`).

---

## 🛠️ Pré-requisitos

* Python 3.x
* Um terminal Linux, macOS ou Git Bash (para Windows)

---

## 🚀 Como Executar

### Opção 1: Executando o script Shell (`.sh`)
O arquivo `.sh` automatiza o processo de inicialização da calculadora. 

1. Abra o terminal na pasta raiz do projeto.
2. Dê permissão de execução para o arquivo (necessário apenas na primeira vez):
   ```bash
   chmod +x calculadora.sh
   ```

### Opcao 2: Executando diretamente pelo Python
Caso prefira rodar o código-fonte principal de forma manual:

No terminal, navegue até a pasta do projeto.

Execute o comando informando o arquivo principal:
  ```Bash
  python calculadora.py
  ```
